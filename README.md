# ✨ Form Forge: Fuzzy-Matching Autofill Chrome Extension for Google Forms

## 📝 Description

`form-forge` is an innovative Chrome extension meticulously crafted to revolutionize how users interact with Google Forms. By leveraging advanced fuzzy-matching algorithms, this extension intelligently processes user input from its intuitive popup interface to automatically and accurately autofill relevant fields within any Google Form. Designed for efficiency and precision, `form-forge` significantly reduces the manual effort involved in data entry, enhances productivity, and minimizes errors, making it an indispensable tool for anyone who frequently navigates or completes Google Forms.

## ⬇️ Installation

To install `form-forge` and begin streamlining your Google Form experience, follow these steps:

1.  **Clone the Repository:** 💻 Start by cloning the `form-forge` repository to your local machine using Git:
    ```bash
    git clone https://github.com/your-username/form-forge.git
    cd form-forge
    ```
2.  **Access Chrome Extensions:** ⚙️ Open your Chrome browser and navigate to the extensions management page by typing `chrome://extensions/` into the address bar and pressing Enter.
3.  **Enable Developer Mode:** 👨‍💻 In the top-right corner of the Extensions page, toggle on the "Developer mode" switch. This will reveal additional options.
4.  **Load Unpacked Extension:** ➕ Click the "Load unpacked" button that now appears on the left side of the page.
5.  **Select Repository Folder:** 📁 In the file dialog that opens, browse to and select the `form-forge` directory you cloned in Step 1.
    Once selected, the `form-forge` extension will be loaded into your browser, and its icon will appear in your Chrome toolbar.

## 🚀 Usage

Using `form-forge` is straightforward and designed for immediate productivity gain:

1.  **Navigate to a Google Form:** 📝 Open any Google Form in your Chrome browser that you wish to autofill.
2.  **Activate the Extension:** 🖱️ Locate and click the `form-forge` icon in your browser's toolbar. This action will open the extension's compact popup interface.
3.  **Input Autofill Text:** ✍️ Within the popup, enter the text or keywords you wish to use for autofilling the form fields. The extension will use this input for fuzzy matching.
4.  **Observe Autofill:** ✅ As you type or after you've entered your input, `form-forge` will dynamically apply its fuzzy-matching logic to the form fields and intelligently populate them with the most relevant data. Experience the magic of automated form completion!
